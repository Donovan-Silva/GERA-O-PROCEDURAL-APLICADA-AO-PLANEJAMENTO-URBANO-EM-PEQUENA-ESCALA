# GERAÇÃO-PROCEDURAL-APLICADA-AO-PLANEJAMENTO-URBANO-EM-PEQUENA-ESCALA
Este trabalho explora o desenvolvimento de um sistema de geração procedural para planejamento urbano em pequena escala, com ênfase na automatização da criação de infraestruturas de ambientes residenciais, integrando normas urbanísticas locais. Diferentemente de abordagens baseadas em inteligência artificial, o sistema irá empregar algoritmos generativos e regras paramétricas para gerar matrizes que representam malhas viárias. O sistema será construído usando técnicas como L-systems para modelagem hierárquica, priorizando coerência estrutural e garantindo que elementos respeitem restrições legais e lógicas de conexão. As principais contribuições buscadas no projeto incluem um arcabouço metodológico replicável para adaptação a normas municipais e a criação de um modelo de geração procedural funcional.
