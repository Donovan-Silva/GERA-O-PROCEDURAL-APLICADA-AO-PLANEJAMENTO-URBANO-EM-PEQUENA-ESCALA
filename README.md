# GERA-O-PROCEDURAL-APLICADA-AO-PLANEJAMENTO-URBANO-EM-PEQUENA-ESCALA
Este trabalho explora o desenvolvimento de um sistema de geração procedural para planejamento urbano em pequena escala, com ênfase na automatização da criação de infraestruturas de ambientes residenciais, integrando normas urbanísticas locais.
